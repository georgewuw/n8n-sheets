Privacy Policy — n8n-sheets

Effective date: 2026-11-18

n8n-sheets is a personal automation application used by a single user (its owner) to connect the owner's own Google Sheets and Google Drive accounts to a self-hosted n8n workflow instance. This policy describes what data the app accesses and how it is handled.

Data the app accesses

  • Google Sheets: the contents of the owner's topic-queue spreadsheet (topic titles, target platform, production status, and result links).
  • Google Drive: files in a designated folder ("图文成稿") where the app uploads finished draft packages (ZIP files containing an article and an image) created by the workflow.

The app accesses this data only through Google OAuth, with the owner's own authorization, and only to carry out the owner's automation described on the home page.

How the data is used

  • Reading queued topics so the workflow can produce drafts for them.
  • Writing the production status and the resulting Drive file link back into the spreadsheet.
  • Uploading the generated ZIP packages to the owner's Drive folder.

Processing takes place on the owner's own server and within the owner's own Google account. Draft text is generated with the owner's own third-party AI API key configured in the workflow; the spreadsheet contents are used as the input for that drafting step.

Sharing

The app does not sell, rent, or share Google user data with third parties. It does not use the data for advertising, and it does not track users. The app has exactly one user: its owner.

Retention and deletion

Data remains in the owner's own Google account and on the owner's own server, under the owner's control. The owner can revoke the app's access at any time from the Google Account permissions page, and can delete the spreadsheet, the Drive files, and the workflow at any time.
